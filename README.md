# Customer Segmentation with K-Means Clustering

A team project for my MBA in IT at the University of the Potomac. We grouped online retail customers by their buying behaviour.

## Tools
Altair AI Studio (RapidMiner) and Excel

## Data
Online Retail II dataset, turned into an RFM table for each customer (Recency, Frequency, Monetary).

## Method
- Cleaned the data: removed missing customer IDs, cancelled invoices, and zero or negative quantities and prices
- Calculated RFM values for each customer
- Normalised the values
- Applied K-Means clustering

## Results
The final team model grouped 5,860 customers into 5 segments: VIP, Loyal, Regular, Occasional and Inactive.

## My Contribution
I rebuilt the workflow on my own from the raw data to check the results. My stricter cleaning left 4,338 customers, using K=4. I shared the comparison with the team so we could review the difference.
